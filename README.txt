MINHA CALISTENIA — PROJETO ANDROID

Este ZIP contém o código-fonte de um app Android simples (Kotlin + WebView).
Recursos: treinos de segunda/quarta/sexta, links individuais de demonstração,
cronômetro de descanso e registro de peso salvo no aparelho.

IMPORTANTE:
- Este é o PROJETO-FONTE, não um APK compilado.
- Para gerar o APK: abra a pasta no Android Studio, aguarde a sincronização
  do Gradle e use Build > Build Bundle(s) / APK(s) > Build APK(s).
- O APK de depuração costuma aparecer em app/build/outputs/apk/debug/app-debug.apk.
- É necessário Android Studio, JDK e Android SDK instalados.
- Os vídeos abrem no YouTube e precisam de internet. Os links de alguns exercícios
  abrem uma busca específica do exercício, para escolher uma demonstração adequada.
